## 二、存疑原文（官方没说 / 说法需保留原样，别替他补）

- **750016 呓语镇**：官方 2.6 版只有一句「位于桑古伊斯狩原下层受蚀地的失落角斗士小镇」；**2.7 版 uid 260006「法比亚纳」** 才补了「即昔日的『呓语镇』。在十六前因狩原黑潮的爆发而覆灭」。两边**谁前谁后官方没给统一说法**——wiki 七丘页的说法是七丘人故意用「呓语镇」来忘掉旧名「法比亚纳」，方向正好相反。按 lead 口径：**同一个镇子，不当两个镇子**，两种说法都写进 note，存疑不圆。
- **750009 圣火**：官方明说圣火本身没有特异效用，只是占卜的媒介；引火矿物「代代相传」的秘要，官方**没说**是哪些矿物、也没说配方。
- **750010 玛涅斯之底**：官方全篇用「相传」「传说」——**传说级设定**。进者获英雄王之力、成为必由之路，同属传说，别当已证实的机制。
- **750018 醒真草**：官方用「传言」——**传说级设定**。药用效果是减缓侵蚀、恢复神志，官方没提它能对付黑潮本体。
- **750020 路标刻像**：「属于某种特殊类型的声骸」是**有观点认为**，官方紧跟一句「该理论目前尚未得到学界广泛认可」；形成自角斗士情绪频率同理。别当定论讲。
- **750004 风潮崖**：「空行节点」是官方原话，官方**没解释**空行如何实现，也**没写**角斗士具体怎么横越狭渊。
- **750013 定向锚**：官方**没交代**制造者、制造工艺与数量，只说「以彻地之楔伴生的地下黑石造」的小装置。
- **750003 彻地之楔**：官方只写「第一次黑潮爆发后被激活」及其力场效果，**没写现状**；「与岁主英白拉多一同自高天降临，受其所辖」照抄未改。
- **750011 槲叶勋章**：官方**没写**评奖标准、颁授程序，也没把它和七丘其它爵位并列。
- **750007 猎号**：官方只写它在狩猎开始/结束时鸣号，**没写**它有战斗力；它本身是公共声骸。
- **750012 狩王鹫**：官方说它「本就以公共声骸形态存在」——**别当它一直是声骸**；它原生于分界山一带（另见 lore-qiqiu 页 uid 850163）。
- **750014 锚定界石**：官方只写它与定向锚**协同**产生力场，**没写**界石单独能不能用。

## 三、撞名表

全库 t 与 alias 归一化后**无碰撞**；本页 18 个 t + 1 个 alias 全部唯一，**无需加限定后缀**。

唯一别名决定：**圣火 → `alias: ['焰光']`**。依据官方原文「一般被称为焰光」，属同一实体的通俗叫法，故收作别名；未把其它页的近名词塞进 alias。

近名 / 同物（**不是撞名**，但最容易讲错，已分别写进各条 note 的「近名」段）：

| 容易混的一对 | 区隔 |
|---|---|
| **呓语镇（本页 750016）** vs **呓语镇（原名法比亚纳）（world-extra 的 `world-fabuiana`）** | **同一个镇子**，法比亚纳是旧名。官方 2.7 版 uid 260006 明写「即昔日的『呓语镇』」，lore-late 页的 `lore-late-fabuiana` 同指此地。t 字符串不同所以不触发 lint 告警，但属同物近名——**保留官方 t「呓语镇」**、**不设 alias**（免得跟 lore-late 的「法比亚纳」撞名），关系写进 note |
| 黑潮造物（本页）≠ 黑潮（`term-blacktide`，terms 页） | 前者是黑潮诞下的类生命体、属残象一种；后者是黑潮本身，也是鸣式利维亚坦的能力 |
| 定向锚（本页，官方英文 Anchor Stone）≠ 隧锚（`term-tunnel-anchor`，terms-official 页） | 只是都有一个「锚」字；隧锚是隧者初到拉海洛时留下的「锚」 |
| 定向锚（Anchor Stone）≠ 锚定界石（Anchor Obelisk） | 官方英文只差一词；前者是装进后者里的小装置，后者是部署装置 |
| 赤林猎场（中上层）≠ 往世花平野（中下层） | 官方明写往世花平野在赤林猎场更深处 |
| 四方殿（官方俗名「圣殿」）≠ 圣火 | 一个是谕女居所兼占卜之所，一个是燃烧矿物产生的火焰 |
| 狩猎（本页）≠ 深塔/矩阵那类爬塔挑战 | 本页是七丘角斗士的线下清剿传统，不是玩家操作 |
