# 官方档案文书页（docs.js）交付说明

## 建了什么
- 文件：`kb/src/entries/docs.js`（新页，**23 条**，id 形如 `doc-<英文短名>`）
- 一条 = 一份文书（不是一个人、不是一件道具）。同一个人的不同文书分条收。
- 全部 `lvl: ['官']`，**0 条【待】**，每条都有非空 `src`。
- `src` 一律：`['https://mc.yakitahome.com/api/info/detail?id=<档案id>', 'source/yakitahome-info-full.json']`
- `note` 逐条写清：官方档案 id + 官方版本号 + 标题栏状态（空/有）+ 原文逐字摘抄。
- 页面渲染体积：**全版 4325 码点 / 精简版 2560**（目标 6000、硬顶 8192；note 与 src 不进渲染页，不占体积）。def 最长 39 码点。
- 本页 23 个 t 互不相同、也未与全库 t/alias 相撞；alias 只加了 4 个原文真出现的叫法：人工太阳、给好心人、消失的巫女、拉科萨。

## 官方原文没交代、我用 tabu 钉住的点
- **诊断1（33011014）**：全文只写「受试样本」，没点名；全库也没有「相机」这条线索 → 不认人（达妮娅声痕在胸口、绯雪在右胯，都不是右小腿外侧）。
- **诊断2（33011015）**：只给「建议留院查看」，没下诊断结论；「观测到症状」≠确诊。
- **30010006 炉芯论文**：官方「评估结果：不予立项」→ 只能写成被否掉的方案，不能写成「炉芯计划失败」，更不能说已经投放过。
- **30010001 人工太阳**：只到阶段三「最终测试：进行中」；异常波形是魏尔伦批注且写着「暂无风险」，不是事故。
- **30010010**：整篇一句、用的是「很可能」，没名字没用途。
- **28050002**：署名只有「梵蒂尔」三字，官方没介绍他是谁。
- **32010002**：官方结论是「并未发现事件中巫女的身影」，三种解释都没被证实。
- **72010102 绸缎**：名字被紫线划去是什么意思、德莉珐其余身份，档案没写。
- **72010100 鉴定报告**：只在标题出现「阈极狭极」，正文一律称「患者」；德莉珐只是医疗报告的出具者。
- **72010107**：是拉科萨的招募口吻（末尾「我是拉科萨！」），不是项目报告；重建进度官方没写。
- **102189701**：官方写明「利用虚质磁暴杀死自己」，是自杀不是事故；同僚才是残星会间谍。
- **102189702**：「他们的尊严，从不在于『征服』」是赛斯坦自己的感想，不是官方对罗伊族的定义；「据他们的记载」是转述。
- **102189703**：他明写「已经放下了自杀的念头」，别和第一篇并成「自杀」；结尾「我终于……回家了……」是他的临终感想。
- **102181710**：磁暴「突然发生」、浓度正常；塔维娅自己写「我们赌了一把，赌输了」，别写成她被磁暴直接杀死。
- **35000002**：信里的「姐姐」「阿布」官方都没点名是谁。
- **33011016 事故说明**：没写是什么事故、在哪、后果如何。
- **33011017**：只说「驳回」，没写她辞呈的原因，也没写后来辞没辞。
- **33011021 / 24 / 29**：各只有一句道具说明，没写用法、没写地点、没写截图内容。
