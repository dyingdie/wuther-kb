## 1. 收录口径

- 一条一人，def 格式与 roles 页一致：**「X属性，Y武器。稀有度，版本（YYYY-MM-DD）上线。」**
- **稀有度不在 infobox 里**，取页面正文首句的写法（限定五星／四星）。wiki infobox 的「星级」栏在角色页上并不总在，写不进去就不写。
- 身份、来历、性格、关系不进这一页 → 靠 rel 指到 chars / chars-npc / chars-npc-2 / person / org / world 页。
- 不写数值、面板、养成强度、定位：wiki 角色页没有「定位」栏，现编就是编。
- tabu 写「哪儿容易说错」：声痕位置、所属团体、别号与真名的区别、同属性不同人、联动角色。
- **别称一条没加**：赞妮/琳奈/莫宁/陆·赫斯/洛瑟菈/清宵/弗洛洛在别的页已经有条目，加别称会撞名报 ⚠。
- src 写的是页面地址 `https://wuwa.huijiwiki.com/wiki/<角色名>`（与 roles 页同款写法）。
- note 里逐条存了 infobox 逐字与抓取日期（2026-10-24），给以后核。
- **排序按上线版本走**：1.2 相里要 → 1.3 釉瑚 → 2.1 菲比 → 2.3 赞妮、夏空 → 2.5 弗洛洛 → 2.7 嘉贝莉娜 →
  3.0 琳奈、莫宁 → 3.1 陆·赫斯 → 3.4 洛瑟菈 → 3.6 清宵 → 3.7 心、锁暝；3.4 的联动角色露西、丽贝卡放最后。
