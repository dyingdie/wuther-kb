## 4. POST /api/search 能不能查中文正文：实测记录

**结论：不能。** 这是**配置文本检索库**（音乐名、歌词、菜单项、任务小标题、术语标题、成就描述、适龄提示），**不是剧情对白库**。中文关键词能命中，但命中的全是配置文本；**中文剧情正文一条都搜不到**。

> ⚠️ 由此产生一条使用纪律：**查不到 ≠ 不存在。** 本报告 §2 里凡判「官方没有」的，都是「这 288 条可见词条里没有」，不能据此断言官方没这个概念。

### 4.1 参数实测

|---|---|
| `{"query":"虚质"}` | total 1，唯一命中 `id=Text_AgeTip_Text`（那段适龄提示），其 `c.en` 里是中文适龄提示全文 |
| `{"q":"虚质"}` / `{"keyword":"虚质"}` / `{"term":"虚质"}` | total 0 —— **参数名只有 `query` 有效** |
| `mode:"exact"` | 无效，仍按 fuzzy 返回 |

| `textVersionStart` 非空 | 直接过滤成 total 0 |
| `storyProgressVersion` / `language` / `lang` / `Accept-Language` 头 | 均不影响结果 |

## 7. 给写条目的人的三条提醒
