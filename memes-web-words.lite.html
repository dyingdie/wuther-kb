全网热梗·句式
==============

【什么时候翻这页】可套用的句式、语气词、谐音梗：把梗用出来的模板
【精简版】只留「是什么 / 什么不能做」，出处备注都删了。要查出处翻同名的 .html

1. ××基础，××不基础 【玩】
   前半句认一件事，后半句在同一维度里反着来：上班基础，发疯不基础
   禁忌：两个短语得在同一个维度上，别拼成病句；别用在正式文书里

2. 低山臭水遇知音 【玩】
   把「高山流水遇知音」故意说低一档，指两个审美不对付的人臭味相投
   禁忌：别在夸人时用，会像骂人；也别在不认识对方时硬套近乎

3. 敬自己一杯 【玩】
   拿敬酒的口气安慰自己或夸别人：辛苦了，值得一杯
   禁忌：别在真需要安慰时显得敷衍；也别变成酗酒话题

4. 助我破鼎 【玩】
   「助我」加「破鼎」，喊人一起干成事的热血话
   禁忌：别在真的要求别人时当命令说；也别用来评价谁行不行

5. 如何呢又能怎 【玩】
   「那又怎么样呢」的阴阳式反问，用来表示不慌、不在乎
   禁忌：别在真需要解释和沟通时用；也别连着用显得欠揍

6. 我去不早说 【玩】
   「我怎么不早说」的感叹，用来表示这事早该告诉自己
   禁忌：别在对方刚说出口时抢着说，显得像马后炮

7. 我将全职在家研究… 【玩】
   「我将全职在家研究 XX」的句式，把一件小事说成要干一辈子的大事
   禁忌：别拿「全职」去承诺真事；也别对长辈用

8. 在中国我们不说… 【玩】
   「在中国我们不说 A，我们说 B」的句式，两段替换，多半是玩梗
   禁忌：别拿真实文化差异开玩笑；别把玩笑话当事实讲

9. 你已急哭 【玩】
   「你已经急哭了」的调侃句式，指对方急得不行
   禁忌：别在对方真难受的时候说；也别用来评价真输不起的人

10. 我要验牌 【玩】
   「我要验一下（是不是真的）」的句式，表示要查证、要对方拿出证据
   禁忌：别真的去要求别人出示什么；别在需要信任的场合用

11. 胆子真是肥嘟嘟的 【玩】
   「你胆子真大」的调侃长句，多用来怼乱来的人
   禁忌：别对真在冒险的人说，容易变成激将；别对长辈用

12. OMG你吓到我了 【玩】
   夸张的惊呼句式，被吓到时用来夸张反应
   禁忌：别在真危险的事故后说；也别拿来压过对方的话

13. 爱你老己 【玩】
   「爱自己」的自嘲说法，把「老己」当自己，累的时候拿来安慰自己
   禁忌：别在别人需要安慰时抢着自嘲；也别当成真的抒情

14. 千百次练习只为这一刻 【玩】
   「练了很多次，只为这一下」的句式，用来给努力找个说法
   禁忌：别拿它当真的自我感动式鸡汤；也别在别人失败时用

15. 预制×× 【玩】
   「预制人生」「预制朋友圈」：把现成的、流水线的东西说成预制出来的
   禁忌：别拿来说真的商品质量；也别用来指责具体的人

16. 活人感 【玩】
   活着的、真实的感觉；形容人或场景不像机器、不像摆拍
   禁忌：别当形容词夸人长相；也别在严肃作品讨论里乱用

17. 班味 【玩】
   被上班磨出来的那股疲惫气味，形容人身上带着打工痕迹
   禁忌：别用来评价别人的工作态度；也别在认真谈工作时抖机灵

18. 情绪价值 【玩】
   一个人或一段关系给人的情绪收益，形容被哄、被安慰到了
   禁忌：别用来评价别人的真情实感；也别当索取安慰的借口

19. 村咖 【玩】
   乡村咖啡馆式的慢生活氛围，指一种远离城市节奏的松弛感
   禁忌：别把它当真的店铺分类；也别用来贬低城市

20. 来财 【玩】
   招财、来财运的吉利话，常用来接别人的祝福或祝人赚钱
   禁忌：别当真的算命词；也别在谈亏损时硬接

21. ×具系列：杯具、洗具、餐具、茶具 【玩】
   用「具」字替换的谐音梗：杯具是悲剧、洗具是喜剧、餐具是惨剧、茶具是差距
   禁忌：别在真出事的人面前用；别把「食具」当骂人话说

22. 蛋定 / 蛋疼 【玩】
   「淡定」与「蛋疼」的谐音，前者装镇定，后者说某事无聊得荒谬
   禁忌：别在真需要冷静处理问题时抖机灵；别用来骂人

23. 稀饭（也作粥） 【玩】
   「喜欢」的谐音，说喜欢某样东西时用
   禁忌：别在正式文字里写；也别当真的在说粥

24. 童鞋 / 肿么 / 酱紫 【玩】
   一串谐音替换：童鞋是同学、肿么是怎么、酱紫是这样子
   禁忌：别对不熟的人连用三个显得刻意；正式场合别用

25. 鸭梨山大 / 毫无鸭梨 【玩】
   「压力山大」「毫无压力」的谐音，拿来说自己压力大或装作没压力
   禁忌：别在真需要支援时只丢这句；也别拿它调侃精神压力的人

26. 木油 / 木有 / 泥 / 骚年 / 大虾 【玩】
   一串谐音替换：木油是没有、泥是你、骚年是少年、大虾是大侠
   禁忌：别在正式聊天里连用；也别拿「骚年」当骂人话

27. 砖家 / 叫兽 / 内牛满面 【玩】
   一串挖苦式谐音：砖家是专家、叫兽是教授、内牛满是泪流满面
   禁忌：砖家、叫兽是骂人，别对正经专业人士用；也别当自嘲乱喷

28. 神马都是浮云 / 干色摸 / 斑竹 【玩】
   一串谐音：神马都是浮云是什么都不值钱、干色摸是干什么、斑竹是版主
   禁忌：「神马都是浮云」别用来真的否定别人的在意的事

29. 数字谐音：520、530、7456、88、666 【玩】
   用数字谐音传话：520 我爱你、530 我想你、7456 气死我了、88 拜拜、666 太厉害
   禁忌：别在正式场合用；别把 2333 当脏话说

30. 3Q / me2 / V5 / +U 【玩】
   一串字母数字谐音：3Q 是谢谢、me2 是我也是、V5 是威武、+U 是加油
   禁忌：别对不熟的人单发看不懂；正式场合别用

31. YYDS / XDJM / 人称缩写 【玩】
   拼音缩写：YYDS 是永远的神、XDJM 是兄弟姐妹；同类还有 GG 哥哥、MM 妹妹、BB 宝宝
   禁忌：别对不懂的人连用；BB 现在多指宝宝，注意场合

32. 扛八袋 / 爱老虎油 / 卡哇伊 【玩】
   一串外来语谐音：扛八袋是加油、爱老虎油是我爱你、卡哇伊是可爱
   禁忌：别当真的日语；也别在认真表白的场合乱接

33. 语气词一组：哈哈、嘻嘻、嘿嘿、嘎嘎、呜呜 【玩】
   按情绪选笑声：哈哈是开心、嘻嘻是撒娇调侃、嘿嘿是得意、嘎嘎是搞怪、呜呜是哭腔
   禁忌：别连发一堆显得敷衍；呜呜别在真难受时乱撒娇

34. 论坛回复套路：围观、打脸、盖楼、潜水、灌水、路过 【玩】
   一套老论坛回帖用语：围观是跟着看热闹、打脸是当场反驳、盖楼是排队回复、潜水是只看不回
   禁忌：年代久远，用多了像复古滤镜；对新词不熟的人别用

35. 四字缩句词模板 【玩】
   把一句话压成四个字的新成语式说法，如「百错仍硕」「你生我梦」
   禁忌：别拿生造词当成语用；一次别连造好几个

36. 中国式×× 【玩】
   「中国式」加一件事的句式，指某做法很有中国特色
   禁忌：别拿真的文化差异当笑料；也别用来指具体人群

37. 牛B / 牛X 【玩】
   北方方言「吹牛皮」的变体，夸人或骂人很厉害
   禁忌：夸人可以，别当骂人脏话；正式场合别用

38. 邪修 【玩】
   非主流但真的有效的那一套做法，反着来反而成了
   禁忌：别拿真会伤身的偏方当建议；也别在正经教程里当方法

39. 外耗 【玩】
   把自己的消耗转嫁给别人，比如情绪、活儿、锅
   禁忌：别用来说别人就是被消耗的；也别在真需要担责时躲
