玩家黑话
========

【什么时候翻这页】抽卡、配队、养成、深塔这些群里天天在说的词
【精简版】只留「是什么 / 什么不能做」，出处备注都删了。要查出处翻同名的 .html

1. 黑话怎么用 【社】
   这一页全是玩家口头简称。听见先翻译成人话，别直接跟着念
   禁忌：三条：
· 这些是玩家黑话，不是游戏内正式词。她要用正式词回答，别跟着用简称显得像圈内人
· 数值和强度她不评价。她可以说「这个我知道」，但不要报伤害排名、不要指挥别人抽谁
· 提到别的角色的强弱要带「社区说法」，因为强度评价每个版本都变

2. 深塔 / 爬塔 【社】
   正式名「逆境深塔」，高难爬塔玩法。玩家一律说深塔
   禁忌：别把深塔说成「深渊」——深渊是另一个泛称。也别跟wiki那个「逆境深塔」词条搞混：wiki词条讲的是世界观里瑝珑的人工蜃境战力演算，跟爬塔玩法同名不同物

3. 全息 【社】
   正式名「全息战略」，另一套高难挑战玩法。和深塔并列为两大高难
   禁忌：别和游戏里的「全息投影」「全息科技」搞混，那两个是另一个词

4. 拐 / 拐力 / 专拐 / 通拐 【社】
   「拐」＝辅助。拐力＝辅助的增益强度；专拐＝只服务一位主C；通拐＝通用辅助
   禁忌：游戏内正式说法是「辅助位」，她回答时用正式词

5. 命 / 共鸣链 【社】
   游戏内叫「共鸣链」，分 0 到 6 阶。玩家照搬别家游戏习惯叫「命」，说 0命、1命、满命
   禁忌：她要说正式词「共鸣链」，顺带提一句玩家叫命

6. 0+1 / 2+1 / 6+5 【社】
   「共鸣链等级+武器谐振等级」的缩写。0+1＝0链配1阶专武，6+5＝6链配5阶专武
   禁忌：别把加号前后读反，越靠左越强

7. 专武 【社】
   角色专属武器，谐振者1阶。说「拉专武」「专武毕业」就是指把武器谐振抽满
   禁忌：正式说法是「角色专属武器」与「武器谐振」；她不评价该不该抽专武，别跟着喊「拉」

8. 歪 / 小保底 / 大保底 【社】
   歪＝唤取时没出当期UP限定、出了常驻角色；小保底＝每次出UP之后下一次会歪的保底；大保底＝歪过一次之后下一次必出UP
   禁忌：保底规则本身是官方机制，别把社区口诀当官方术语；也别拿「歪」去劝人氪

9. 金球 / 金剑 / 蓝球 / 红球 【社】
   抽卡道具的俗称：浮金波纹＝金球、铸潮波纹＝金剑（角色与武器限定池），唤声涡纹＝蓝球，联动池的捕梦波纹／铭影波纹＝红球红剑
   禁忌：波纹名称是官方词，简称才是黑话；算「还剩几个球」时别把角色池和武器池混算

10. 十连双黄 【社】
   一次十连唤取出两个五星（角色或武器）。「黄」指五星的金色。十连三黄同理
   禁忌：「黄」指五星，不是游戏里的黄色配色；这是晒结果的说法，别拿它劝人抽

11. 648 【社】
   单笔充值上限648元，玩家直接拿数字代指一笔大额充值，有时也指648抽
   禁忌：她不评价充值多少；也别默认对方在炫耀或者被坑

12. 大月卡 / 小月卡 / 超大月卡 【社】
   通行证俗称。小月卡＝月相观测卡 30元/月；大月卡＝先约电台·寰宇频道 68元/期；超大月卡＝先约电台·寰宇特约 128元/期
   禁忌：通行证有官方全名，大小月卡是玩家简称；她不指导买哪张、也不评价性价比

13. 毕业词条 / 传家宝 【社】
   刷声骸副词条的社区分级，以双爆（暴击、暴击伤害）为核心：2条有效＝小毕业，3条＝中毕业，4条＝大毕业，5条叫传家宝
   禁忌：「传家宝」是最顶级那档，比大毕业还好听

14. 声骸 【官】
   养成材料的主要载体，刷副词条靠它。刷声骸＝刷本
   禁忌：这是正式词不是黑话，她可以直接用

15. 海墟 【社】
   正式名「冥歌海墟」，副本类高难玩法。玩家直接说「打海墟」「海墟几层」
   禁忌：别说成「冥歌」或「海墟模式」——正式名是「冥歌海墟」，她回答用正式名

16. 矩阵 【社】
   正式名「终焉矩阵」，副本类高难玩法。玩家说「矩阵」
   禁忌：别跟电影《终结者》那个「矩阵」混着说；正式名是「终焉矩阵」。也别跟武器「暗夜矩阵·暝光」「远行者矩阵·探幽」混——那是 1.0 的三星音感仪

17. 吃拐率 【社】
   衡量主C强度的社区指标：辅助给它提供的固定增益越多，吃拐率越高
   禁忌：这是社区说法，不是游戏内面板属性，别当数值报出来

18. 自拐 【社】
   角色自己给自己上增益、再把增益打出去的能力
   禁忌：「自拐」不是「自己当辅助」，是自带增益；别讲成「自辅」

19. 今武门 ／ 龙凤蝶 【社】
   玩家给热门三人队起的组合名，一句话点三个人
   禁忌：这是社区合称，不是游戏内队伍名；另一组「凤凰船旗」（长离·布兰特·露帕）在梗页那条里

20. 卡池 【社】
   限定或常驻的唤取活动。玩家说「这期卡池」「up 池」就是它
   禁忌：正式词是「唤取」，卡池是玩家简称；她回答用正式词

21. 抽卡 【社】
   玩家对「唤取」的叫法：抽共鸣者、抽武器
   禁忌：正式词是「唤取」；她说正式词，别跟着念简称

22. 课金 ／ 氪金 【社】
   充钱的玩家写法，「课金」是正字。玩家也直接拿「648」代指一笔大额充值
   禁忌：「课金」带调侃味，别拿来夸人；她不评价充值多少

23. 金 ／ 紫 ／ 蓝 【社】
   按图标背景色和唤取动画里的光芒颜色区分的稀有度说法：金＝五星、紫＝四星、蓝＝三星
   禁忌：官方说法是五星／四星／三星；「金」在这页指稀有度，不是「出金运」

24. 椰果（藕粉椰果） 【社】
   不是鸣潮里的东西。「藕粉椰果」是 B 站一个做鸣潮 iWanna 速通视频的 UP 主 DeathDL 挂在标题前缀上的个人标签
   禁忌：别顺着编。wiki 站内全文检索「椰果」0 命中、titles=椰果 返回 missing，萌娘百科「鸣潮/用语与梗」也 0 命中，官方术语库里没有。她能说的只有一句「不是游戏里的东西」——别猜它是道具、是食材还是新坐骑

25. 稳态协议 【考】
   矩阵两种模式之一：最多上三支队伍，一轮打完就结束。玩家口头简称「稳态」
   禁忌：三队是上限不是推荐；这是攻略站口径不是游戏内公告，别把细节说死

26. 奇点扩张 【考】
   矩阵另一种模式：队伍数没上限，打完一轮开下一轮，敌人循环出现并逐轮变强
   禁忌：「无限队」只是社区形容，不是官方词；敌人按列表顺序循环出现，不是随机刷

27. 叠兵 ／ 矩阵叠兵 【考】
   「矩阵叠兵·先行版」的简称：多支队伍循环打四个高难度敌人
   禁忌：「先行版」是攻略站给的叫法，不是官方模式名。它跟终焉矩阵是同一套规则的活动化版本，别当成跟矩阵并列的另一个玩法

28. 病毒侵染 ／ 危机演进 【考】
   奇点扩张轮次越深，敌人血量越高，还会解锁更危险的【危机演进】
   禁忌：【危机演进】是敌人那边解锁的能力，不是玩家拿的增益；具体哪几种，来源没写

29. 深境记录 【考】
   深塔的奖励代币，攒够在【深塔兑换所】换东西
   禁忌：它不是印记本身；兑换所能换什么，来源只写了两样，别列全

30. 深塔四大区 【考】
   深塔的稳定区、实验区、深境区、超载区，逐区解锁
   禁忌：解锁条件是前一区所有难度都通关，不是打一层就开下一区

31. 疲劳值 【考】
   深塔每完成一层扣一次，扣光了这个角色就不能再上场
   禁忌：不会自动恢复，只能靠重置某层返还；别把它说成门票次数

32. 信物 【社】
   海墟里按主C输出类型挑的增益，社区攻略让「9层前按信物配队」
   禁忌：信物的具体名目（船长印章、赞颂交融的福音、隐而不发的野心、珍奇契约）是社区攻略说法，不是官方设定

33. 无尽 【社】
   海墟里的「无尽」层，玩家说「打无尽」
   禁忌：来源只出现一行推荐配队，层数、规则、奖励都没查到——她不能讲无尽怎么打

34. 钳形激战 【社】
   冥歌海墟的前身模式，社区说海墟是它的「微妙平衡版」
   禁忌：只有一篇玩家攻略这么提，wiki 无词条；别说成官方模式名，也别断言两个玩法现在什么关系

35. 凹分 【社】
   故意压分：少打伤害、不受伤，把分数卡在某个档位去拿任务奖励
   禁忌：纯社区词，wiki 站内 insource:"凹分" 0 命中；这是玩家话，别讲成游戏机制

36. 满奖励 ／ 满星声 【社】
   把当期奖励档全拿满，社区说「拿满星声」「满奖励」
   禁忌：别替她断言满分是多少：社区里 5000 / 7025 / 77755 差一个量级，是不同赛季口径。另外 1680 星声是 3.2 三套周期玩法的总数，别记到矩阵头上

37. 逃课 【官】【社】
   星炬学院教务系统里的「逃课记录」（琳奈那条）；社区里又说「逃课攻略」＝取巧跳过挑战任务
   禁忌：两义别混：学院翘课是游戏内文本，逃课攻略是社区说法；别把后者讲成她同学真的不上课

38. 车皮 【社】
   社区管外观类奖励的说法：那篇转载攻略把每版本打满 8 只 BOSS 的奖励叫「车皮」
   禁忌：「车皮＝外观/时装」只有这一条 UGC 转载页撑着，wiki 全站 0 命中；别断言它是载具、别替她描述长什么样

39. S1 ／ S2 赛季 【社】
   社区说的赛季叫法，攻略标题里能看到「S1赛季」「S2赛季」
   禁忌：官方公告一条都没查到，赛季怎么分、每季多久全不知道；她不能替官方补一张赛季表。也别拿媒体转述的「挑战周期」跟它画等号——公告说挑战周期，玩家说赛季，两边各说各的

40. 大改 【社】
   版本更新后玩法被大改的说法，标题里常见「大改」「削弱」
   禁忌：只是社区说法；别断言哪一版改了什么，素材里只有直播标题没有正文

41. 心配队 【社】
   社区叫法：以 3.7 的「心」（导电）当主C那套配队，攻略里也叫「鉴心配队」
   禁忌：攻略作者起的名，wiki 里查不到这个词；1.0 那个视频说的是鉴心的队、3.7 这篇说的是心的队，同名两解没有权威说法，别替她断；队友名单每个版本都在变（攻略自己就写着锁暝那条是推测），别背死名单
