全网热梗·游戏圈
================

【什么时候翻这页】游戏圈与二次元圈的梗：跨游戏流行语、圈层黑话
【精简版】只留「是什么 / 什么不能做」，出处备注都删了。要查出处翻同名的 .html

1. 肝 【玩】
   为了提升角色或装备强度长时间反复刷副本
   禁忌：**别拿它劝人真的熬夜肝**：说顺口可以，劝人透支身体不行

2. 脱坑 【玩】
   不再玩这款游戏，通常伴随长草期或强度不满
   禁忌：**别劝人别脱坑也别劝人回坑**；她只说明现象

3. 长草期 【玩】
   版本更新少、新内容迟迟不来的阶段
   禁忌：**长草期不等于版本号小**，别跟版本对照表混着说

4. 保底 【玩】
   抽卡攒够一定次数必出目标物的机制
   禁忌：**保底不保证你想要的那一个**，机制细节别乱补

5. 井 【玩】
   抽卡计数单位，一井就是攒满一次保底所需的货币
   禁忌：**各游戏的一井金额不一样**，别说成固定数

6. 欧皇 / 非酋 【玩】
   抽卡运气特别好的人叫欧皇，特别差的人叫非酋
   禁忌：**是运气自嘲不是嘲讽**，别拿非酋说人笨或手黑

7. 歪 【玩】
   抽到了不想抽的角色或装备
   禁忌：**不是抽卡机制的正式词**，但玩家都这么用

8. 限定 【玩】
   只在特定卡池或活动期出现、错过就不再有的内容
   禁忌：**「限定」不等于「绝版」**：复刻是常有的，别吓唬人

9. 复刻 【玩】
   限定内容重新开放一段时间
   禁忌：**复刻时间不保证**，别许诺「以后一定返场」

10. 联动 【玩】
   游戏与其他作品或品牌合作推出的内容
   禁忌：**联动是合作不是同一世界观**，别把联动角色算进本游戏设定

11. 出货 【玩】
   抽到了想要的东西
   禁忌：**出货是运气不是实力**，别拿来评价谁玩得好

12. 爆仓 / 吃土 【玩】
   抽卡把存款或生活费一次掏空，就叫爆仓、吃土
   禁忌：**别怂恿人加氪**；真吃土了也别调侃到让人难堪

13. 白嫖 【玩】
   不花钱拿到手：免费领、活动送、签到拿
   禁忌：**别默认每款游戏都给白嫖机会**，具体看该游戏

14. 买号 / 卖号 【玩】
   直接买别人练好的账号，或把自己的号卖掉
   禁忌：**涉及账号安全与实名**，她不评价也不参与；别教人绕过实名

15. 毕业 【玩】
   某个角色的养成已经到位，不用再练了
   禁忌：**「毕业」是相对某一套装备和某个版本说的**，别当成绝对结论

16. 专武 【玩】
   为某个角色量身设计的那把武器
   禁忌：**专武不等于最好**，它只是适配度高；别拿来否定别的选择

17. 命座 【玩】
   角色突破重复获取后解锁的额外能力
   禁忌：**命座是重复获取的代价**，别把「几命」说成另一种抽卡

18. 坐骑 / 皮肤 【玩】
   角色的坐骑与外观装扮，属于外观向内容
   禁忌：**外观不直接影响强度**，别把它和强度评价混着说

19. 圣遗物 【玩】
   另一款游戏里叫圣遗物的装备系统，鸣潮对应的叫声痕
   禁忌：🚫 **鸣潮没有圣遗物这套东西**：对应的是声痕与声骸，别照搬机制

20. 深渊 / 忘却之庭 【玩】
   带层数评分的长期挑战副本，鸣潮对应逆境深塔与冥歌海墟
   禁忌：**这是别的游戏的名字**，鸣潮那边要说的是逆境深塔、冥歌海墟

21. 凹分 【玩】
   为了凑够副本评分反复刷
   禁忌：**别拿凹分当炫耀**，也不要说「随便打打就行」

22. 御三家 【玩】
   新号开局白送的三个角色
   禁忌：**各游戏御三家不一样**，别把别家的开荒三人组照搬

23. 骗氪 【玩】
   厂商用各种手法诱导玩家花钱的说法
   禁忌：**这是吐槽的说法**，别当成事实断言具体厂商

24. 数值膨胀 【玩】
   新版本角色数值高到让老内容失去意义
   禁忌：**是社区的评价**，官方不会这么说；别拿来当定论

25. 唯强度论 【玩】
   只看数值高低、不看其他玩法与喜好的评价方式
   禁忌：**别拿它去否定别人的玩法乐趣**；也不要在她面前把这套当真理

26. XP 怪 【玩】
   为了拿某个角色的额外能力而一直刷的日常角色
   禁忌：**别把 XP 怪说成必需**，抽不抽看个人

27. 配队 / 阵容 【玩】
   把几个角色编成一组一起推关的玩法
   禁忌：**配队方案是建议不是标准答案**，别把某一队说成唯一解

28. 抽卡玄学 【玩】
   抽卡前做的一堆没有依据但大家都做的仪式
   禁忌：**没有实际作用**，她可以陪玩但别把玄学说成方法
