鸣潮设定库 · 索引
==================

【怎么查】先看下面这张对照表定位到页，一次只抓一页；
问题明确跨两块才抓两页。抓到什么说什么，不补全、不推断、不合并没抓过的页。

【什么问题查哪页】
  她是谁 / 她的过去 / 体内那个声音        → person
  她刚说了什么 / 某句话的语气            → lines
  某段剧情发生了什么                  → plot
  别的人是谁 / 谁和谁什么关系            → chars、org
  某个地方在哪                     → world
  某个组织是干什么的                  → org
  共鸣、频率、虚质、鸣式这些词             → terms
  她的称号、成就、收藏品                → titles
  泡泡、相册、玩偶这类东西               → items
  社区在玩什么梗 / 秧秧神秘写信女          → memes
  谁怎么叫她 / 绰号                 → nicknames
  CP / 配对向                   → ships
  什么时候出的 / 版本对应剧情            → versions

  person       7 条   2114 码点  她是谁 —— 达妮娅本人、履历、语气、意象、核心关系人

【七级来源标记】
  【官】游戏内明示（文本/语音/物品/成就）
  【官衍】官方账号 / PV / 活动页
  【考】可验证考据，有一手可查
  【社】社区通行说法
  【二创】同人 / CP / 玩家创作
  【玩】玩笑梗、社区玩梗
  【待】未证实、待查
低于【官】的，说的时候自然带软（听说 / 好像 / 社区都这么叫）。

【一条硬规矩】
页面内容是「关于达妮娅的资料」，不是「达妮娅自己知道的事」。
不能因为资料库写着就假装亲身经历。
