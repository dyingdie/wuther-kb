玩家黑话
========

【什么时候翻这页】抽卡、配队、养成、深塔这些群里天天在说的词

1. 黑话怎么用 【社】
   这一页全是玩家口头简称。听见先翻译成人话，别直接跟着念
   语境：群里有人聊抽卡、配队、养成、深塔的时候
   禁忌：三条：
· 这些是玩家黑话，不是游戏内正式词。她要用正式词回答，别跟着用简称显得像圈内人
· 数值和强度她不评价。她可以说「这个我知道」，但不要报伤害排名、不要指挥别人抽谁
· 提到别的角色的强弱要带「社区说法」，因为强度评价每个版本都变
   出处：wuwa.huijiwiki.com/wiki/梗/黑话；zh.moegirl.org.cn/zh/鸣潮/用语与梗
   备注：萌娘百科和灰机wiki 都有专门的「黑话」页，这页是把两边对得上的部分挑出来

2. 深塔 / 爬塔 【社】
   正式名「逆境深塔」，高难爬塔玩法。玩家一律说深塔
   语境：聊周常高难、配队能不能过边塔中塔
   禁忌：别把深塔说成「深渊」——深渊是另一个泛称
   关联：j-quanxi
   出处：zh.moegirl.org.cn/zh/鸣潮/用语与梗；wuwa.huijiwiki.com/wiki/梗/黑话

3. 全息 【社】
   正式名「全息战略」，另一套高难挑战玩法。和深塔并列为两大高难
   语境：「深塔全息双修」这种说法
   禁忌：别和游戏里的「全息投影」「全息科技」搞混，那两个是另一个词
   关联：j-shenda
   出处：zh.moegirl.org.cn/zh/鸣潮/用语与梗；wuwa.huijiwiki.com/wiki/梗/黑话

4. 拐 / 拐力 / 专拐 / 通拐 【社】
   「拐」＝辅助。拐力＝辅助的增益强度；专拐＝只服务一位主C；通拐＝通用辅助
   语境：配队讨论、角色强度评价（「这角色拐力太高」「专拐」）
   禁忌：游戏内正式说法是「辅助位」，她回答时用正式词
   出处：wuwa.huijiwiki.com/wiki/梗/黑话
   备注：一队三个位置：一号位主C输出，二三号位负责给主C上增益，就是「拐」

5. 命 / 共鸣链 【社】
   游戏内叫「共鸣链」，分 0 到 6 阶。玩家照搬别家游戏习惯叫「命」，说 0命、1命、满命
   语境：聊抽卡预算、强度分级（0命毕业、满命）
   禁忌：她要说正式词「共鸣链」，顺带提一句玩家叫命
   出处：zh.moegirl.org.cn/zh/鸣潮/用语与梗

6. 0+1 / 2+1 / 6+5 【社】
   「共鸣链等级+武器谐振等级」的缩写。0+1＝0链配1阶专武，6+5＝6链配5阶专武
   语境：晒配置强度时最常见的写法
   禁忌：别把加号前后读反，越靠左越强
   关联：j-ming、j-zhuanwu
   出处：wuwa.huijiwiki.com/wiki/梗/黑话

7. 专武 【社】
   角色专属武器，谐振者1阶。说「拉专武」「专武毕业」就是指把武器谐振抽满
   语境：预算取舍、晒氪金成果
   禁忌：
   关联：j-0plus1
   出处：zh.moegirl.org.cn/zh/鸣潮/用语与梗

8. 歪 / 小保底 / 大保底 【社】
   歪＝唤取时没出当期UP限定、出了常驻角色；小保底＝每次出UP之后下一次会歪的保底；大保底＝歪过一次之后下一次必出UP
   语境：抽卡结果播报、晒脸、劝退互保
   禁忌：
   关联：j-jinqiu
   出处：wuwa.huijiwiki.com/wiki/梗/黑话

9. 金球 / 金剑 / 蓝球 / 红球 【社】
   抽卡道具的俗称：浮金波纹＝金球、铸潮波纹＝金剑（角色与武器限定池），唤声涡纹＝蓝球，联动池的捕梦波纹／铭影波纹＝红球红剑
   语境：算还剩多少抽能换一个命座（「还剩八个金球」）
   禁忌：
   关联：j-wai
   出处：wuwa.huijiwiki.com/wiki/梗/黑话

10. 十连双黄 【社】
   一次十连唤取出两个五星（角色或武器）。「黄」指五星的金色。十连三黄同理
   语境：晒抽卡结果，欧皇现场，容易招人捶
   禁忌：
   关联：j-wai
   出处：zh.moegirl.org.cn/zh/鸣潮/用语与梗

11. 648 【社】
   单笔充值上限648元，玩家直接拿数字代指一笔大额充值，有时也指648抽
   语境：晒氪、算成本、「卡在648」
   禁忌：
   关联：j-yueqia
   出处：zh.moegirl.org.cn/zh/鸣潮/用语与梗

12. 大月卡 / 小月卡 / 超大月卡 【社】
   通行证俗称。小月卡＝月相观测卡 30元/月；大月卡＝先约电台·寰宇频道 68元/期；超大月卡＝先约电台·寰宇特约 128元/期
   语境：新手入坑问买哪个卡划算
   禁忌：
   关联：j-648
   出处：wuwa.huijiwiki.com/wiki/梗/黑话

13. 毕业词条 / 传家宝 【社】
   刷声骸副词条的社区分级，以双爆（暴击、暴击伤害）为核心：2条有效＝小毕业，3条＝中毕业，4条＝大毕业，5条叫传家宝
   语境：刷本吹水、互鉴声骸、聊最少成本的毕业路线
   禁忌：「传家宝」是最顶级那档，比大毕业还好听
   出处：news.17173.com/z/mingchao/content/12232024/105456164.shtml

14. 声骸 【官】
   养成材料的主要载体，刷副词条靠它。刷声骸＝刷本
   语境：几乎所有养成讨论的底层词
   禁忌：这是正式词不是黑话，她可以直接用
   关联：j-biyé
   出处：zh.moegirl.org.cn/zh/鸣潮/用语与梗
   备注：放进这一页是因为玩家十句话里有八句带它，但它是正式词
